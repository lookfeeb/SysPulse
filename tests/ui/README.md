# 隔离前端验收

运行 `npm run dev -- --port 5175`，打开 `http://127.0.0.1:5175/tests/ui/index.html`。

该独立入口使用 Tauri 官方 mockIPC/mockWindows，加载真实页面与组件，但所有 IPC 都被拦截；未知命令直接报错。模拟删除、扫描和 OAuth 仅修改浏览器内存，刷新页面恢复。它不包含在生产构建入口中，不验证原生文件系统、硬件或真实 OAuth 服务。

数据：一万条 Codex/Claude 会话、80 条消息的分页正文、一个清理路径、一个模拟 OAuth 服务。测试类型检查：`npx tsc -p tests/ui/tsconfig.json`。

2026-09-28 已人工验收：
- 1000×680 窗口：会话首屏 12 行，End 到第 9999 条后 11 行；搜索重置滚动，选择和正文第 2 页正确。
- 删除确认取消；确认删除模拟会话后搜索结果清空。
- 清理模拟扫描、详情、工具链取消勾选、空队列禁用按钮、项目目录管理弹窗。
- 800×560 最小窗口：详情弹窗标题、内容与底部操作可见。
- 模拟 OAuth 未授权→已授权、Token 刷新、撤销确认→未授权。
- 概览、AI 管理、磁盘清理、通用、硬件、历史页面切换和无数据状态。

观察：通用页已有 Ant Design InputNumber addonAfter 弃用提示；不属于运行异常。尚未验证真实桌面 IPC、真实扫描/删除、OAuth 网络交互、持续帧率及峰值内存。

第四轮复验：增加 12 个模拟采样点后，概览指标及两组图表可显示；MCP 模块拆分后，模拟授权回显与搜索空结果通过，控制台无错误。

配置失败验收：打开 `/tests/ui/index.html?config-failure`，切到通用页，会显示“无法读取设置 / 模拟配置读取失败”。点击“重新读取”后，先显示读取中，再恢复表单。该场景已于 2026-09-28 通过。
